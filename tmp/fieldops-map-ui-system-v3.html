Contrato propuesto

FieldOpsMapShell debe ser el unico contenedor visual para mapas. Recibe centro, zoom, capas, acciones y modo: complex, terrain, board.

MapMain puede conservar la logica actual de bounds, zoom persistido y navegacion. El cambio principal es extraer shell, toolbar, leyenda, popup y panel.

Filament deberia usar el mismo contrato de datos en Blade: mapa grande, marcadores, leyenda y tarjeta de ubicacion. No copiar pantallas completas.
